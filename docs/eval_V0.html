Pour améliorer la proposition, voir ci-dessous les critères non validés dans les tableaux et les commentaires.

Barème de la notation :
"oui" = présent dans la proposition => 1 point x Coefficient
"oui, mais" = présent partiellement dans la proposition => 0,5 point x Coefficient
"N.I." = absent de la proposition => 0 point
"non" = contre dans la proposition => 0 point
